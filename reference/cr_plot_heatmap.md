# Heatmap of channel medians across groups

Heatmap of channel medians across groups

## Usage

``` r
cr_plot_heatmap(
  experiment,
  channels,
  group_by = "treatment",
  scale = c("none", "row", "column")
)
```

## Arguments

- experiment:

  A `cr_experiment`.

- channels:

  Character vector of channel names.

- group_by:

  Design column defining rows. Default `"treatment"`.

- scale:

  One of `"none"`, `"row"`, `"column"`. Scaling centres the values, so
  the fill switches from the sequential to the diverging palette.

## Value

A `ggplot` object.
