# Standard deterministic figure dimensions

Standard deterministic figure dimensions

## Usage

``` r
cr_figure_size(
  size = c("single", "double", "report", "square"),
  units = c("mm", "in")
)
```

## Arguments

- size:

  One of `single`, `double`, `report`, or `square`.

- units:

  `"mm"` or `"in"`.
