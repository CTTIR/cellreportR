# Construct a concise report QC table

Construct a concise report QC table

## Usage

``` r
cr_report_qc(
  criterion = character(),
  observed = character(),
  acceptance = character(),
  status = character(),
  source = character()
)
```

## Arguments

- criterion, observed, acceptance, status:

  Vectors defining reportable QC rows.

- source:

  Optional source identifiers.
