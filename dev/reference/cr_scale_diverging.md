# Continuous diverging scale

Continuous diverging scale

## Usage

``` r
cr_scale_diverging(
  midpoint = 0,
  aesthetics = c("colour", "fill"),
  mode = c("colour", "grayscale"),
  ...
)
```

## Arguments

- midpoint:

  Explicit neutral midpoint.

- aesthetics:

  `"colour"` or `"fill"`.

- mode:

  Colour mode.

- ...:

  Passed to the gradient scale.
